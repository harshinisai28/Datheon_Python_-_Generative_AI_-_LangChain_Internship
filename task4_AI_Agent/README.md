
# Smart Expense Tracker

A Python and Streamlit application for recording income and expenses.

## Features

- Income and expense tracking
- Total balance calculation
- Income versus expenses bar graph
- Expense category bar graph
- Daily income and expense line graph
- Budget progress and alerts
- Transaction history and search
- Delete transactions
- CSV download
- Local data persistence
- Readable dashboard with large text

## Installation

python -m pip install -r requirements.txt

## Run

python -m streamlit run main.py

## Data Storage

The application automatically creates transactions.csv and budget.txt
in the project folder when data is saved.

## Technologies

Python, Streamlit, Pandas
